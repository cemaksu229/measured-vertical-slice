# Measured: QA audit (demo eve, 22 Oct 2026)

## Summary verdict
**Not ready yet, but close.** No step of the flow is a dead end: X on the paywall goes to Home, Reset demo returns to Promise, and answers persist across restarts. Typecheck, lint and expo-doctor all pass (20/20).
**Two P0s need fixing before tomorrow.** (1) On a 360dp-wide Android phone the first screen's hero number renders as "1…". (2) The app still ships as "VerticalSlice" with the default Expo icon and a blank splash, which fails a §11 rubric item.
**The 12 P1s are mostly quick fixes.** They cover Home re-entry into onboarding screens, paywall layout and cancel path, honesty copy, child-path copy, and the stale dark-mode exports. About 2–3 hours of work in total.

Evidence: new captures from a fresh web build in `design/tools/qa/shots/` (scripts: `design/tools/qa/build.mjs`, `capture-qa.mjs`, `widths.mjs`, `sheet.mjs`). The contact sheets are `_s1.png` … `_s11.png`. Web captures cannot show haptics, native font fitting or Expo Go behaviour; those items are in the "Needs real device" list at the end.

## Needs real device (check by hand, iOS **and** Android, Expo Go)
1. **Expo Go SDK 58** opens the project on every phone (the store build of Expo Go supports only the latest SDK). Note the exact Expo Go version.
2. **Widths:** check Promise and Height big numbers on the smallest Android in the team (360dp, e.g. Galaxy S2x) and on an iPhone mini/SE (P0-1, P1-11). Also check with large system font (P2-13).
3. **Ruler drag feel** on a mid-range Android: is it smooth? Is there one selection haptic per tick? Does it snap on release? Does the Parents horizontal ruler fight the vertical ScrollView? Is "I don't know" easy to hit?
4. **Haptics:** selection on Goal, About tiles and rulers; light on CTAs; success on the Building finish, the Reveal and Home ticks (web cannot test these).
5. **Notifications:** "Turn on reminders" shows the OS dialog. It appears only the first time per Expo Go install, so on later Reset-demo runs no dialog appears; rehearse with that in mind. Check that no LogBox toast covers the paywall (P1-9). Prefer `npx expo start --no-dev --minify`.
6. **Restart mid-onboarding:** answer up to Parents, kill Expo Go, reopen. Answers should be prefilled and nothing should crash during hydration.
7. **Safe areas:** progress bar under the notch/Dynamic Island, the paywall X reachable (44pt), CTAs clear of the home indicator / Android gesture bar, Welcome top spacing (P2-6).
8. **Back navigation:** Android hardware back and iOS edge swipe on Reveal (should go to Parents, not Building), Welcome (P2-7) and Home (should exit, not re-enter onboarding). Check Home → See Pro → Start my free week → Welcome → Start week 1 → back (P2-8).
9. **Dark mode:** toggle the system theme with the app open. Check silhouettes contrast (P2-11) and white flashes on transitions (P2-10).
10. **Splash/icon:** after P0-2, the Expo Go loading screen shows "Measured" and the new icon on an anthracite background.
11. **Fonts:** Clash Display and General Sans load in Expo Go (fallback to the system font would show on `fontError`).
